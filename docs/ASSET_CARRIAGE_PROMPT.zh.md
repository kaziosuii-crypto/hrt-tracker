任务身份与最终用途
请把这次任务当作一份可直接交给游戏美术团队执行的二维合成资产制作单，而不是“画一张具有某种气氛的海报”。你要制作的唯一交付物是一个原创的电车车厢内部环境背景图层，将实际用于私人健康应用 HRT Atlas 的页面切换。它会和另行制作的透明乘客剪影、近景衣肩遮挡层、独立标题字标组成约两秒的网页动画。本次只画环境，不画乘客，不画标题，不画界面，不画任何数据。图片必须离开文字说明以后仍然明确显示“摄影机在人已经乘坐进去的电车车厢内”。不是从站台看向电车，不是轨道对面的列车侧面，不是车站候车区，不是列车驶入隧道的外景。这个区分是最高优先级，画错空间即使很漂亮也不可使用。

视觉参考与原创边界
视觉方向参考 Persona 5 / Persona 5 Royal 的通勤镜头与游戏菜单里硬朗的平面图形语言，但必须建立独立资产，不照搬任何原作截图、角色、标志、特殊字体或车厢贴图。这里说的参考，不是泛泛的“日系漫画”，也不是红黑滤镜，而是极强的黑白明度组织、轮廓完整的负形、克制而准确的红色节奏、可独立作为图层的构图，以及让观众几乎瞬间识别场景的图形简化。环境不能变成复古版画，不能变成灰蒙蒙的写实插画，不能画成带大量碎线的精细漫画背景。它应该像经过专业游戏 UI 美术人员重新设计过的电车内部：物理空间可信，平面色块干净，重要轮廓突出，细节服从合成用途。

镜头所处的具体位置
想象一位成年人站在日本城市通勤电车中央通道上，背后是另一侧的长条座椅，眼睛约在距离地板一百四十五至一百五十五厘米的位置。摄影机不是站台上，也不是悬在车顶，不是俯视车厢，不是在车尾顺着长通道拍向远处。本画面朝向车厢侧面的对座墙壁，视线大致垂直于对面车窗平面。画面能看到对面宽大的车窗、窗下长条座椅、窗上方的内装面板、从顶棚横杆垂下来的吊环，以及少量竖直扶杆。采用接近正面的横向构图，轻微透视可以存在，但不能让左右两边向很深的消失点收束。不要广角鱼眼，不要夸张倾斜，不要荷兰角，不要“摄像机在轨道外拍到整节车”的任何迹象。

为什么必须是这种镜头
最终手机用户会看到一段非常短暂的通勤印象，而不是有时间辨认所有细节的风景画。吊环出现在头顶、长椅位于下方、扶杆穿过近中景、窗户在乘客头肩后面，这四组结构必须一起说明“车内”。如果只剩下一排门窗和红色横条，就很容易被理解成车外侧面，必须避免。你应该优先保留车厢内的空间关系，而不是列车外形。这里不需要列车车头、车轮、铁轨、站台边缘、黄色盲道、车站立柱、户外接触网或站台灯箱。任何这些外部识别物都会把这个资产带回错误的场景，应完全排除。窗外只能是低对比的深色或纯黑，不出现站台人群和城市景观。

画布与输出形式
输出单幅横向环境图，推荐一千五百三十六乘一千零二十四像素，三比二比例，完整不透明背景。不是拼图，不是九宫格，不是多张概念草图，不是资产说明页，不要带标尺、箭头、注释或边框。整个画面本身就是将要在浏览器中显示的环境层。边缘应当可以向外延伸，左右不需要漂亮的封闭画框；它会在不同屏幕比例下被裁切。画面不能包含任何你想让开发者后期擦除的说明文字，也不要画出假的透明棋盘格。图片不需要透明背景，本次环境层必须有明确可控的底色；透明资产属于之后的乘客与近景图层，不在这张图里解决。

纵向区域的精确分配
请按画布高度百分比组织：顶部零至十二为深黑顶棚与细少量白色灯带；十二至二十七为横向吊环承重杆、吊带和三角吊环；二十七至五十八为对面车窗与少量门内侧轮廓；五十八至八十五为窗下内墙与长条座椅；八十五至一百为车内地板的深色平面。比例可以有小幅自然变化，但吊环不能缩在最上面一条几乎看不见的细边里，座椅也不能占掉一半画面。最关键的是中上部的吊环要清楚，乘客头部将出现在高度三十至五十五附近，所以吊环必须比头部更高，且保留能够看见的空间。不要把吊环画成站台上方的电线，也不要把灯管误画成车外架空结构。

横向区域与中心安全区
手机端最终可能只显示画面中间大约三分之一的宽度，所以中心百分之三十五至六十五宽度必须独立成立。在这个中心区域内，应完整看见至少一个三角吊环、一个大车窗或车门内侧窗口的一部分、窗下长条座椅的明显结构。中心不能恰好是一块没有辨识度的纯黑立柱，不能是一整面空白墙，也不能是全部主体都在左右边缘而中间没有内容。左右两侧作为横向扩展，继续呈现同一节车内的窗户与座椅，但不要让左右各自成为独立场景。横向节奏要连续，一眼能够感到自己身在同一个车厢，不是三张列车照片拼在一起。

吊环系统的具体形状
吊环是本资产的重要识别物。请绘制五至七个可辨识的日本通勤电车三角或圆角三角吊环，每一个有短而笔直的吊带，从同一根车内横向金属扶杆下垂。吊环应该是白色厚实形状配黑色轮廓，中心为黑色或深色镂空，而不是细得像线稿的三角形。每个吊环的大小相近，沿横杆有规律但不机械的间距。不要让它们随机飘浮，不要与电线连接，不要画成衣架，不要画成拉链，不要让三角形底边穿进窗玻璃。吊带和横杆的连接必须在物理上成立，没有断裂、无端分叉或漂移。中心安全区至少保留一个完整吊环，左右可以有被画面边缘裁掉的吊环，这能增强摄影机已经置身车内的感觉。

扶杆与空间深度
画面可以有两根主要竖直扶杆，一根靠左三分之一附近，一根靠右四分之一附近，尽量避免正中间被粗黑杆完全切开。扶杆从顶棚区域延伸至地板，具有非常简洁的白色高光边和黑色主体，不能复杂写实反射。扶杆直径相对画幅应很细，约占宽度一至二个百分点，不能像站台承重柱那么粗。它们是车内抓握用的金属杆，不能带砖块贴面、方形柱脚或车站编号。通过这两根扶杆和后面的窗墙之间轻微的前后关系建立空间即可，不需要复杂透视。所有垂直线大致平行，画面稳定，好让后续人物层的运动承担主要动感。

对面窗户的处理
主要可见两至三段宽车窗或车门内侧窗，车窗位于内墙上方，与座椅形成可信的车内关系。窗框可以是厚白轮廓和黑色密封条组合，几何形状以带极轻圆角的矩形为主，不能像可爱卡通的巨大圆泡。玻璃内侧大面积深黑，可以用极少数斜向白色窄块提示车内灯光反射，但不要使用真实城市夜景照片质感，不要画清晰窗外建筑，不要画出另一列完整电车。玻璃不应该成为充满杂乱纹理的视觉噪音。窗框、墙面和横杆之间必须符合内部装修的结构，不能让一张普通列车外侧贴图冒充车内窗口。

座椅的形状和位置
座椅是车内长条通勤座椅，不是餐厅沙发，不是面对摄影机的一排航空座椅，也不是站台公共长凳。它沿对面墙壁水平延伸，靠背在窗下，坐垫略微向摄影机伸出。用大块纯黑作为主体，在椅背分隔或坐垫前缘使用少量红色色块。白色或浅灰可以用于座椅侧面的壳体，但不必强调人体工学细节。座椅下方可有一条简化黑白通风面板，不要密密麻麻的小孔，最多几组规则的短条。座椅前方的地板保持深黑，最多一条宽度克制的白色边缘，避免大量透视格子造成地板比吊环还抢眼。

门内侧与墙面的区别
可以让画布最左或最右边出现部分车门内侧，门边的竖向抓握结构与车窗框应互相一致。门的红色面板是辅助识别和构图，不要整面红色外壳，不要画列车外部的车身长条广告。车门必须在同一个内部墙面上，门的顶部与车内顶棚连接，地面没有站台缝隙，没有轨道，没有外部台阶。若某个细节有可能让观众误以为站在车外，就简化或去掉它。画面应当像从车厢里的乘客视角截取的一帧，不像模型师展示整节列车的产品渲染图。

色彩数量与面积约束
主色必须是纯黑、纯白、鲜明的深红或绯红，允许一个中性的中灰辅助内墙结构，但不要出现奶油色、棕褐色、泛黄纸张、金色和暖灰旧照片色调。大致面积比例可以是黑色百分之五十五、白色百分之二十五、中灰百分之十五、红色百分之五。红色不是把整个背景刷成大红，不是所有窗户发红光，也不是大面积渐变光效。它应当出现在少数有明确用途的位置，例如一段车门面板、座椅边缘或细窄内饰条。后续字标本身已经有红色，因此环境中的红色必须有节制，确保人物剪影与字标有自己的视觉层级。

线条与图形简化
所有主要轮廓都应该在缩小到三百九十像素手机宽度时仍然成立。使用中等偏粗的黑线或黑白形状交界，不要靠成百上千根发丝线来描述结构。窗框和吊环边缘应干净，轮廓转折明确。细节要经过选择：只保留说明“车厢内”的关键结构，不保留商品广告、螺丝、接缝编号、座椅织物颗粒、磨损痕迹和写实污渍。没有任何需要观众放大后才看得到的精工展示。远看先看到黑白分区，中看看到车窗与扶杆，近看才看到少量结构线。这种由大到小的阅读顺序比“细节越多越好”更重要。

明确排除的渲染风格
不要摄影，不要三维写实产品渲染，不要带金属拉丝的高光，不要空气透视，不要胶片噪点，不要烟雾，不要霓虹灯晕，不要电影镜头耀斑，不要柔焦，不要水彩，不要铅笔，不要油画，不要复古丝网印刷磨损，不要泛黄漫画纸。可以有极少量、非常规则的漫画网点，但只局限在一小块浅灰辅助区域，总面积小于画面的百分之三，且不能盖在吊环或窗框的边缘上。整体更接近干净的游戏 UI 平面合成图，而不是一幅装饰性插画。请尤其避免上一类常见失败：精细逼真的车站背景加一条红线，然后声称它已经具有 Persona 的视觉方向。

与后续乘客图层的合成关系
本图的前面将有两层透明的站立通勤者：远景人物大约占画面高度百分之五十至六十五，中景人物从腰部延伸到画面底边，头部在三十五至五十五附近。他们会遮住大部分座椅和下半部分窗户，所以不要把唯一的“车内识别信息”安排在座椅底部。吊环横杆、完整吊环、上窗框是即使有人群挡住以后仍应看得到的东西。背景不需要在这些区域增加抢眼装饰。请把人物将要出现的位置作为构图的一部分考虑，但不要真的画人形、虚影、脸、身体轮廓或占位灰色人。人物留给独立图层制作，以便前中远景能够以不同速度运动。

近景遮挡的工作原理
最终过场的页面切换会发生在另一个大尺寸衣肩剪影遮住画面的时候。那不是本张图需要完成的功能，因此不要为了遮挡在背景中央画黑色巨块，不要画一个巨大的假人物，不要画红色横条擦屏。环境层必须从头到尾保持自身的空间连续性：它只做非常轻微的横向相机平移，幅度约为宽度的百分之二。图像左右都应保留足够结构余量，让这种小幅平移不露出边界或显示突然断掉的窗框。不要设计依赖一张海报完整边框的构图，因为网页会裁切和移动它。

手机竖屏的实际使用场景
最终最重要的屏幕约为三百九十乘八百四十四像素，纵向比例非常窄。浏览器将对本背景做中心裁切，或单独提取中间区域制作竖屏资源。请主动想象：只剩中间一扇窗、一截椅背和上面的吊环时，观众是否仍然知道自己站在车厢里面。如果不知道，说明构图不合格。中心的吊环不能刚好被上方浏览器安全区吞掉，所以它的主体应从画面高度百分之十六延伸到二十七附近，不要贴在零至五区域。画面上部也不要全部是漆黑顶棚，否则竖屏会像一块黑布遮住镜头。下方不是主要叙事区，但要保留稳定的地板与座椅关系，不能变成一张没有空间的平面纹理。

桌面端的使用场景
桌面屏幕会显示更多左右内容，横向构图应自然延展。不要在左右两侧放两套不同风格的门，不要把窗户的高度画得不一致，不要让同一根横杆在画面中断裂。左中右都属于同一节车厢，重复元素有节奏但保持真实结构。在宽屏下，观众应感觉“站在拥挤电车里，朝对侧看”，而不是“看到一列摆在站台上的车”。允许两侧门框出画，也允许吊环在边缘被裁切，这比完整展示所有物件更有镜头感。地面和座椅不要采用极深消失点，以免中心裁切以后失去车厢内的逻辑。

画面情绪与设计判断
情绪是都市通勤的短暂停顿：安静、有重量、图形感强，带一点游戏菜单的戏剧性，但不是恐怖电车，不是废弃车站，不是战斗竞技场。没有血迹、武器、警告标识、紧急红灯或灾难场景。健康应用需要可靠、清晰，转场可以鲜明但不能制造生理威胁感。画面不需要表达“医疗”“激素”“身体预测”，也不出现医学影像或药品广告。它只是让用户在栏目之间穿过一个原创的通勤镜头。白色形状要干净，黑色要有足够沉稳的连续面积，红色承担少量节奏，观众会自然理解环境，而不必阅读任何文字。

必须为空的文字区域
这张图不要包含任何可读文字，也不要用乱码假装日文站名、广告、警示语。不要有品牌、列车编号、目的地、时钟、路线图文字、Logo、签名、水印或图片边缘的制作标签。所有栏目名称与应用标识将在另外的透明字标上添加。本图里原本适合贴广告的位置可以留成简单纯灰矩形或直接省略，但不要因此画成空旷的广告展板。特别禁止把 HRT Atlas、Persona、P5、Royal 或任何游戏的名称写进环境。视觉参考不代表把参考名称作为画面内容。

结构正确性与常见错误清单
吊环不能漂浮，扶杆不能穿过座椅背后又突然在前面出现，窗户不能与座椅几何关系矛盾，地板不能露出轨道，窗框不能变成外侧铆钉车身。灯管在车内天花板，不在露天站台顶棚。车厢扶杆是细金属杆，不是混凝土柱。长椅安装在窗下，不是摆在玻璃外面。红色内装是一小部分，不是对面整列电车的车身。三角吊环中心是正常镂空，不要变成字母或眼睛。尽量减少重复生成导致的歪斜和多余结构。每一种设计选择都应服务于“电车内侧横向观察镜头”的明确读法。

图层资产的技术自检
输出前请按图层用途检查：第一，图片本身是一张不透明环境，不包含准备另做的乘客；第二，中心三分之一的竖裁切保留车内识别物；第三，所有重要结构有完整轮廓，不依靠纹理来辨认；第四，顶部与左右留有可平移的出血；第五，黑白红色块缩小后没有混成浑浊灰色；第六，没有文字、水印、真实品牌或原作素材；第七，没有站台、铁轨、列车外观等错误空间信号。不要把检查表画进图片，这些只是你在制作时必须遵守的约束。最终只返回环境图像，不返回解释文字、不返回概念板。
