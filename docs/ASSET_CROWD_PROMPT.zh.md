这是一份原创游戏过场二维分层资产制作单。请先认真查看随附的真实游戏逐帧截图，再按照本制作单制作一张可以被切分为三个独立透明图层的素材页。此次参考非常明确：Persona 5 原游戏里电车通勤过场的站立乘客群像。我们需要学习其不透明的灰色块、简化的轮廓和通勤姿态，而不是用黑白细线、透明幽灵和复杂背景模拟它。不要照描原作人物，不要复制原图贴图，不要把原截图切出来。所有人物必须原创，最终用于 HRT Atlas 私人健康应用的页面过场。原图仅作为空间和形状处理的视觉参考，不作为可直接进入网站的成品。

一、输出物是什么
输出一张横向素材页，宽一千五百三十六像素、高一千零二十四像素。素材页由三个横向等高区带组成，每一区带的高度约为三百四十一像素。三个区带之间留少量完全透明的间隔，每个区带内部的内容必须完整，不能有头部、手掌或吊带跨越到另外一个区带。背景整体透明，不要画白底，不要画灰底，不要画黑底，不要画伪透明棋盘。开发者会按照上、中、下三个区带分别裁切，因此必须严格遵守分区。不要画分区线、编号、标签、文字和说明。三个区带的功能分别是远景乘客群、中景乘客群、近景肩背遮挡群，而不是同一张图重复三次。

二、参考图如何使用
随附第一张是真实游戏电车转场的一帧，第二张是同一场景的静态通勤参考。请参考这些图中人物站立的身体重心、抬手抓吊环的姿态、背对镜头的大衣轮廓、群体由前向后叠置的关系，以及人物之间用不同的实心灰色区别深浅的方式。不参考其中任何具体发型组合、脸型、服装款式、站位、乘客人数、图中时间日期、游戏字体、界面、Logo、水印。尤其不要复用原作人物和服装纹章。我们的作品是原创通勤群像，不能让人认为直接复制了原作角色。可以借鉴画面为什么清楚，但必须重新设计每一个轮廓。

三、最重要的视觉原则
所有人物的身体必须是不透明、连续、实心的色块。前方人的大衣遮住后面的人时，后面的人、背景窗框和任何线条都不能穿透这件大衣。不要降低人物透明度来制造远近，远近只能通过颜色明度、大小、轮廓细节数量和遮挡次序表达。不要使用半透明灰色薄膜，不要在人物上增加玻璃质感，不要画幽灵般重叠的双影。上一类失败素材的主要问题就是窗框透过衣服、几个相同人物叠在一起看不清楚，这次必须彻底避免。只允许在轮廓最外侧一像素左右使用正常抗锯齿透明度，人物内部应完全不透明。

四、灰阶色板
不要使用纯白的人脸和密集白色衣缝，不要使用艳红围巾和红背包作为每个人的装饰。本次只使用几档中性偏冷灰色。远景人物主体使用接近十六进制三三三八三八和四五四九四六的深灰；中景人物主体使用接近六五六九六一和八二八五七八的中灰；近景人物主体使用接近四四四八四二和五八五c五二的灰色。脸、头发和衣服可以相差一个档位，但不能使用发白的脸配纯黑衣服。最亮的颜色不超过接近a零a三九五的灰色，最暗的内部细节不低于接近二二二六二五。色彩应平静、清楚、具有车厢人潮的剪影感，不是恐怖场景，也不是高对比角色立绘。

五、轮廓与内部细节的关系
人群首先靠外轮廓成立，内部信息非常少。头部可以是简化的头发块和无五官脸块；衣服可以有一至三条比主体稍暗的宽线表示领口、袖子或袋子，不要精细缝线，不要金属拉链，不要发丝，不要皮革纹理。轮廓线应是比主体深一点的细暗边，但不是围住每个人的一圈粗白描边。原作参考之所以不糊，是因为每个人有稳定的大形，局部轮廓和遮挡清楚，不是因为每个人都画满漫画线。请用减法设计，让缩小到手机宽度后仍能清楚区分谁在前面、谁在后面。

六、远景区带的明确内容
最上方区带绘制八至十位匿名成年乘客。他们站在车厢内部，不行走，没有迈步动作。多数是胸部或腰部以上的轮廓，身体下端延伸到本区带的底边。头顶有高低变化，排列具有自然节奏。至少两个人抬起一只手臂，手掌握着一个小型三角吊环；吊环的细短吊带朝上延伸但不能越过区带顶部。其他乘客可以低头看手机、抱着包、抓住自己的肩带、侧身看向车门。尽量让头与头之间有小段清晰的透明负形，而肩膀与大衣下半部相互连接成连续群体。整个群体占区带宽度百分之九十五以上，不要左右各留很大的空白。

七、远景人物的密度
远景乘客数量多，但不是黑压压无法辨认的一团。人物可以相互遮挡百分之十五至三十，不要每个人只露一只眼睛或者半个耳朵。至少六个头部应该可以在手机缩小后分辨出来。身材高矮、肩宽、头发长度和朝向应变化：有高个子的短发上班族、矮一点的短发女性、微卷发的人、戴简单帽子的人、头发向后束起的人。不要让所有人看起来是同一位主角的复制，不要每个人都穿同样的高中校服。衣服为普通通勤外套、衬衫、针织衫和背包，不能出现学校徽章、品牌或游戏服装。

八、中景区带的明确内容
中间区带绘制五至六位更大的站立乘客，身体仍然到区带底边，头部比最上方远景区带更大，每个人的肩背形状更容易辨认。中间可以有一个背向镜头的大衣乘客，但不要照抄参考图正中央的人物。可以把背向人物移到偏右三分之一的位置，衣领形状采用普通短立领，肩上有一条宽而简洁的斜挎包带。左边安排一个侧身低头看手机的中年乘客，右边安排一个短发成年人抬手抓吊环。其他位置安排抱着托特包的人与长发侧影。每个动作都应有正常的身体支撑关系，手臂与肩膀连接明确，没有多余的手指、手臂或袋子。

九、中景如何与远景区别
中景不靠透明度区别远景，而靠更浅、但仍然克制的灰色块和更明确的轮廓。中景的肩、头和手掌大约比远景放大一点四倍至一点八倍，衣服下端更宽，人与人的遮挡关系更清楚。不要把远景那一整排简单复制放大，因为开发者会将两个图层叠在一起，重复脸型和肩型会立即露馅。中景人物的朝向节奏应不同：远景若多数偏左，中景可以以背向、偏右和正侧面形成错落。每个群体可以连续成带，但人物内部不能透明，叠起来时前层就是正常遮住后层。

十、近景区带的明确内容
最下方区带只绘制两至三名从摄影机极近处经过的乘客肩背。这里不是完整全身人物，不要画腿，不要画鞋，不要把小小的头放在空旷背景里。需要的是胸背与肩膀占据大部分区带的巨大轮廓，头顶可以被本区带的顶部裁掉，衣服下半部必须延伸到本区带底部。最主要的一位背向或侧背向乘客应占宽度百分之五十至六十五，另一位位于一侧，形成自然重叠。至少在横向中间百分之六十的范围，人物衣服应从顶部连续覆盖到底部，不能存在穿透的透明洞。

十一、近景遮挡的功能
近景将用于在关键帧遮住页面的绝大部分，因此它必须有很宽的、实心不透明的身体面积。不要给近景人物画成细腰、大腿分开的全身站姿，因为那种轮廓没办法遮住竖屏。不要画一个泛黑矩形冒充身体，也不要添加无意义的矩形背景来补面积。正确方法是让摄影机真的非常靠近一个通勤者的大衣背部，衣领或肩线只占边缘一点点，主体是宽阔的胸背。形状的左右边缘可以有肩膀自然向下延伸的弧度和衣袖转折，中心则是完整的衣料色块。这个区带不需要读出表情，需要读出人体遮挡的体积。

十二、人物姿态的准确要求
这是站在行进电车里的乘客，不是街头走路的人群。身体重心大致在脚下，肩膀可以略偏，抬手的人手肘有小幅自然弯曲，不必都伸得笔直。看手机的人的头微微向下，手机靠近胸口，不要把手画在脸前遮住所有头部。抱包的人用前臂搭在包上，托特包大形完整。背向人物的肩背略有体积，但仍然用平面灰块表达。不要夸张奔跑、战斗、摆拍、时装走秀或英雄站姿。都市通勤感来自普通动作和拥挤尺度，而不是每个人都做强烈动作。

十三、透明负形的具体处理
透明区域只存在于人物外面、头部上方、局部手臂与身体之间，以及不同人物在头肩附近留下的小缝隙。不要在大衣胸背内部打洞，不要在黑色头发内部制造透明裂纹，不要把脸部空白当成透明。脸本身应是一块灰色，头发是另一块略深的灰色。吊环中心可以是透明孔，因为它确实是环；手握住吊环的部分应不透明。若一个区带的肩背已经连续到下缘，底边就是不透明，不应渐隐到透明。禁止上下边缘羽化，禁止大范围柔边遮罩和底部雾化。

十四、画面清晰度的验收尺寸
素材页单个区带会在网页里缩放、平移和裁切。请想象每个区带被单独切下来，以四百像素左右宽度显示，人物头肩是否仍然清楚。如果头发、衣缝和五官变成糊在一起的小白线，那就是不合格。如果灰色衣服内部出现背景穿透的细线，那也是不合格。正常的清晰度来自大形稳定，脸和头发一至两块颜色，衣服一至两块颜色，手和手机一至两块颜色。所有人物应该有清楚的外轮廓，并且不会因为缩小而变成不知道是什么的抽象碎片。

十五、不要把素材页做成完整场景
这张图不要画车窗、车门、座椅、扶杆长线、车站、铁轨或天花板横梁。环境已经有另一个独立图层。你可以在抬手人物的手上画小型吊环和非常短的吊带，仅仅用于让姿态读起来正确，不要在上方加一整根横梁把所有分区连接在一起。这样开发者才能让不同人群轻微独立移动，同时背景吊环仍然有清晰位置。图片也不能带任何 UI 字样、标题、日期、数字、状态条、操作提示、漫画拟声词、Logo 或水印。这些都不是这张图的职责。

十六、构图不要过度居中对称
三条区带可以各自有不同的重心。远景左边略密右边略疏，中景中间留出一个头肩层次明确的关系，近景主肩背偏左或偏右都可以。但每条带都要横向连续，避免所有人物集中在中央只占一半宽度。左右两端可以有人物被边缘裁切，形成“人潮还延续到画面外”的感觉。最上方和中间区带的头部不要被区带顶部截断，近景区带可以有意裁掉头顶，因为镜头靠得极近。注意区分有意的近景裁切与失误的分区越界。

十七、色彩细节再次限定
本次不需要红黑白 UI 字标风格的人物。原游戏通勤过场与菜单并不是同一种明度安排：菜单可以强烈黑白，通勤过场的人群则依赖几档沉稳灰色。请不要因 Persona 5 这个名字就给每个人穿红色围巾、黑色制服、白色面具。绝对不出现怪盗面具、特殊发型、校服徽章或标志性的角色造型。我们需要的是匿名成年人，五官简化但不是空洞恐怖的白脸。人物的灰色内部完全不透明，让同一条带中不同人物之间也有稳定的前后区别。

十八、轮廓节奏与后续运动
最终运动不是让所有人物跳跃或疯狂摇晃，而是群体横向擦入，略微停留，再横向擦出。人群层内部只有极轻微的视差和重心变化。因此资产必须在静止时就成立，而不依靠高速运动模糊来掩盖错误。请不要画拖影，不要画速度线，不要把同一个人的前后帧叠在一起。每个人只出现一个清晰姿态。也不要生成多帧连拍或动画序列，虽然这是动画资产，但当前交付格式明确是一张包含三个独立区带的透明素材页，不是视频和不是多帧动作表。

十九、平面美术的制作质感
外轮廓可以有轻微手绘感，但边缘要锐利。衣服大形可以有一块较深的阴影，阴影的边缘也是明确平面形状，不是柔和空气喷笔。不使用织物照片、铅笔排线、水彩晕染、油画笔触、旧纸颗粒、胶片噪点、光晕或反射。不要把素材做成精细的写实人物速写。游戏过场在手机上只有约两秒，观众看见的是形状、动作和层次，所以细节必须克制。每一处多余细线都会在小屏幕里增加噪音，请优先删掉它，而不是认为细节越多制作越高级。

二十、人物多样性与真实比例
所有人物都应当是普通成年人，男女、身高、发型、肩宽、衣领和包袋有区别，但不要使用夸张身体比例。头部与肩膀比例自然，大衣不贴成身体预测图，脸没有特定真实人物相貌。不要把人物画成机器人、僵尸、儿童或统一模具。抬手的手掌应握住吊环，手腕不反折，手机拿在合理位置，背包带跨过肩膀而不是漂浮在空中。多人的肩背关系有重叠，但不要产生一个人长出两个头、三只手或错误融合的身体。

二十一、最终交付前的自检
请确认三个区带确实互不跨越，各自可以按固定高度裁切；远景、中景、近景有不同人物而非复制；内部色块是不透明的；没有透明幽灵和白色细线密集穿透；近景肩背足够宽而且上下出血；所有人物都是站立通勤姿态；颜色是几档平静冷灰，不是黑白面具或红围巾；没有背景、文字、日期和水印。请不要把这些检查项写进图片，它们只是制作约束。最终输出只有一张透明的三层人群素材页，不附加解释或分镜标注。

二十二、最后强调的优先级
首先保证人群轮廓与分层清楚，其次保证三条区带能独立裁切，再次保证近景的遮挡面积，最后才是衣服细节。如果真实参考图中的某个具体人物很有辨识度，请另设计一个完全不同的人，而不是复制。通过原创轮廓实现相同的通勤空间感和不透明灰阶层次。不要用细线冒充画面完成度，不要用透明度冒充景深，不要用光晕冒充空气感。我们要的不是一张看起来热闹的海报，而是一组每一个像素都能在网页动画中发挥作用的工程化原创美术资产。
